# Habit Tracker

A simple, single-page habit tracking application built with vanilla JavaScript and CSS.

## Features

- **Add New Habits**: Create habits with custom names and target frequencies (1-7 times per week)
- **Track Progress**: Mark habits as complete for specific dates
- **Streak Calculation**: View current and longest streaks for each habit
- **Weekly Goals**: Set and track weekly completion targets
- **Statistics Dashboard**: Overview of total habits, daily completions, and weekly progress
- **Data Persistence**: All data is saved locally using localStorage
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. **Open `index.html`** in your web browser
2. **Add a new habit** using the form at the top
3. **Mark habits complete** by clicking the "Mark Complete" button
4. **View your progress** in the statistics section
5. **Delete habits** using the trash icon button
